# Content Pod

Document quality. Proposals, investor updates, memos, reports — any written deliverable that needs review or co-writing. Use for any request mentioning: review this, check this before it goes out, edit this proposal, co-author, write a report, give feedback on this document.

## Skills

| Skill | Status | Trigger |
|-------|--------|---------|
| document-review | live | "review this", "check this before it goes out", "edit this", "feedback on this doc" |

## Standards

Document type classification: before reviewing, identify whether the document is internal (team memos, strategy docs, skill files) or external-branded (customer-facing copy, investor updates, press releases). Internal uses the style guide. External adds company brand voice.

Review output format: every review produces severity-graded findings (showstopper, gap, inconsistency, underspecified, suggestion) plus a readiness verdict (ready / revise / rework) plus a concrete fix for every showstopper, gap, and inconsistency.

No vague feedback: "improve the headline" is not actionable. "Replace 'Transforming property compliance' with 'Compliance tracking for 50-500 unit portfolios'" is.
