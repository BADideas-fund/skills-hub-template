## How to use this

When you want to build a new skill:

1. Check if it's already in the backlog or in someone else's wave.
2. If not, add it to the backlog with a one-line description.
3. When you're ready to build, move it to Wave 2 with an owner assigned.
4. When built and tested, move to Wave 1 (shipped) and update REGISTRY.md.

If a skill in Wave 2 is blocked on another skill, list that dependency. Don't start blocked skills until the dependency is live.
